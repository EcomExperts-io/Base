# Assets

Files referenced from `.liquid` via [asset_url](https://shopify.dev/docs/api/liquid/filters/asset_url).
Flat directory, no subdirectories, so every filename is unique theme-wide.
Icons stored here are inlined with [inline_asset_content](https://shopify.dev/docs/api/liquid/filters/inline_asset_content).
